Change the words, keep the look

Select any printed text and edit it — the result is recomposed from the document’s own letterforms, so it stays pixel-faithful. Fix a typo, swap a name or a date, and no one can tell.

FONT MATCHING

Nine faces, really embedded

Added and edited text is set in a real font matched to the print — sans, serif, mono, geometric, humanist, condensed, rounded, slab or grotesk — embedded on export. Latin text stays real, selectable type; Cyrillic, Greek and CJK are drawn through a crisp 3× raster so they look right on any reader, at the cost of being selectable.

TRUE REDACTION

Gone, not hidden

With “true redaction” ticked on export, covered content is removed from the page’s own drawing program — not a black box a journalist can copy-paste under. Leave it unticked and the box is only a box.

AI blending — bring your own model

Like the magic erasers in phone photo editors, but for print: a vision model reads the text you drag over, matches its typeface, weight and color — and hands you the pen.

Change the words. It’s rebuilt from the page’s own letters — or a matched embedded font — so it looks like it was always there.

And the one you already know from your phone — but honest

Press C and draw around a logo, a stamp, a photo: it comes off the page. A phone has to invent the pixels underneath, because a photograph is all it has, and you can always tell — the smear where a pattern should continue, the ghost of the shape. A PDF is not a photograph. It is the instructions that drew the page, so ReshapedPDF asks the model only which marks are the object and then deletes those instructions. What appears underneath is not a guess at the background. It is the background, exactly as the document’s author drew it — down to the rule that ran under the logo. On a page that is genuinely just pixels — a photograph, a flat scan — there are no instructions to delete, so it rebuilds the texture the way a phone would, and tells you that is what it did.

Every installer is built by CI from this repository and attached to the GitHub release with a SHA256SUMS.txt beside it. Verify with shasum -a 256 --ignore-missing -c SHA256SUMS.txt (on Windows, certutil -hashfile <file> SHA256). The file lists every platform's build, so without --ignore-missing it reports the ten you did not download as failures.

Or use the web app — same editor, zero install.
 These builds are not code-signed yet. That means your system will stop you the first time, and here is exactly how to get past it.
macOS 15 (Sequoia) and newer — open it once, let it be blocked, then System Settings → Privacy & Security → scroll down → Open Anyway. (The old right-click → Open trick no longer works; Apple removed it.) Or, in a terminal: xattr -dr com.apple.quarantine /Applications/ReshapedPDF.app.
macOS 14 and earlier — right-click the app → Open → Open.
Windows — SmartScreen → “More info” → “Run anyway”. Linux — chmod +x ReshapedPDF-*.AppImage.
Signing certificates are on the list; a free tool today beat waiting for them.
